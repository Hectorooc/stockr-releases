# Stockr releases

Public downloads and update information for **Stockr**, a Windows app for analysing US companies from their SEC filings.

- **Download:** [latest release](https://github.com/Hectorooc/stockr-releases/releases/latest) → `Stockr-Setup-<version>.exe`
- **Website:** https://hectorooc.github.io/stockr-releases/ (the `docs/` folder)
- `latest.json` is written by the Stockr build; the app reads it to offer in-app updates. Don't edit it by hand.

The source code is private.
